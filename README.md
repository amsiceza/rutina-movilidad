# Rutina de Movilidad y Flexibilidad

Guía web de una sola página, pensada para abrir desde el móvil durante el entrenamiento: rutina diaria de 30 minutos con foco en movilidad de cadera, más el resto del cuerpo (columna, hombros, cuello y piernas).

- Ilustraciones propias por ejercicio
- Pasos, tiempos y repeticiones por ejercicio
- Casilla "Hecho" por ejercicio (se guarda en el propio móvil)
- Rutina exprés de 10 minutos, plan semanal y errores habituales
- Modo claro / oscuro automático
